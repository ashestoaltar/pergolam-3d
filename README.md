# Pergolam 3D

Standalone CPQ preview for **Anchor.PERGOLAS_Pergolam**. Parametric Three.js model driven by the same attribute names as the Infor ruleset.

## Run locally

```bash
python3 -m http.server 8787 --bind 127.0.0.1
```

Then open http://127.0.0.1:8787/
